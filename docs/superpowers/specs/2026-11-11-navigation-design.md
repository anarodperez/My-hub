# My Hub: shared navigation and group experience

The user delegates visual direction after rejecting isolated card refinements. Build a coherent mobile-first product, with persistent primary navigation and discoverable group actions. Preserve existing data, permissions, confirmations and route URLs.

## Direction contract

THESIS: a personal space for discovering things and making plans with friends. Stable navigation and compact, readable compositions replace disconnected full-screen group pages.

OWN-WORLD: warm white surfaces, pale violet background, plum active controls, sage availability. Existing Manrope and Source Sans fonts, Phosphor icons and local decorative photographs. No new dependencies.

STORY: choose Amigas, open a group, read plans, inspect availability or find people and invitations without losing the primary destinations.

FIRST VIEWPORT: a 224-point navigation rail on desktop, four labelled destinations below content on mobile. Group identity uses a small photographic cover and a consistent four-tab bar. Plans lead; People exposes invitations before member management.

FORM: code-led app refinement; seed: none (unavailable). The user explicitly delegates the direction: “no se solo quiero que este precioso”.

FINISH: verify navigation selection, route actions, mobile reflow, text scaling, group permissions and regressions. Update DESIGN.md and record visual verification limits honestly.

## Scope

Use one navigation shell around authenticated routes, retain focused editor/modal behavior, unify group headers and tabs, refine shared colors and spacing. Keep uploads, database changes and new features outside this pass. Decorative covers remain bundled defaults, not members' photographs.
